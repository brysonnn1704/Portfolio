## 🎨 Design Philosophy & Sensibility

Inspired by the refined, tactile Japanese digital product design language of [Mild Sugar Design](https://mildsugardesign.jp/):
- **Warm Paper Canvas**: Soft, natural cream tones (`#FAF8F5`) paired with nocturnal studio dark mode (`#141312`).
- **Tactile Micro-Interactions**: Gentle Japanese-style cursor stalker, interactive sticker badges, and fluid modal deep dives.
- **Human-Centered Typography**: Pair of geometric display font (`Outfit`) with high-readability body sans (`Plus Jakarta Sans`).
- **Inclusive Accessibility**: WCAG 2.1 AAA contrast ratios, keyboard trap management, and complete `prefers-reduced-motion` compliance.

## 💻 Local Development

### Prerequisites
- Node.js (v18+)
- Python (v3+) or any static HTTP server

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/brysonnn1704/Portfolio.git
cd Portfolio

# Build production assets (minified CSS & JS)
npm run build

# Start local preview server
npm run dev
# Server runs on http://localhost:8080/
```
